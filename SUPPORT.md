# Support

- **Bug reports:** open a GitHub bug report with safe reproduction steps and
  relevant logs or screenshots. Never include API keys in logs or issues.
- **Feature requests:** use the feature-request template and describe the
  user problem and workflow.
- **Usage questions:** open a GitHub issue with enough context to reproduce
  the question.
- **AI providers:** Open Merchant is bring-your-own-key. Provider account or
  billing questions go to your provider (Anthropic or OpenAI); issues here
  cover the app's integration, not provider availability.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md). Do not
  disclose suspected vulnerabilities in public issues or pull requests.
