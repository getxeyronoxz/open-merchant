# Open Merchant 1.0.0 — launch thread

Ready to post. Each post stands alone; the thread reads top to bottom. Every post is under 280
characters. The demo GIF is embedded in the README, so link it in post 2.

Tone precedent: [`build-in-public-thread.md`](build-in-public-thread.md). Same voice — concrete,
specific, and honest about what is still unfinished. No claim here is one the changelog does not
back.

---

**1/**
Open Merchant 1.0.0 is out. A local-first desktop workbench for one question: is this product actually worth pursuing? Windows, macOS, Linux. github.com/getxeyronoxz/open-merchant

**2/**
The demo in the README is the whole loop, run for real: create a project, record evidence, compare competitors, enter costs, calculate the margin, write the report. No keys, no network.

**3/**
1.0 promises exactly one thing: your project folder keeps opening. It is plain JSON and JSONL on your disk. Read it without us, in ten years, with anything.

**4/**
The math is not AI. Unit economics run on arbitrary-precision decimals in a deterministic core, pinned by golden fixtures carried over from the original Rust engine. No floating point. No LLM near a number.

**5/**
Phase 3 added a read-only MCP server. Your assistant can read evidence, competitors, snapshots, economics, reports. It registers zero tools — a write is refused at the protocol level — and every read is written to your run log.

**6/**
Also new: plugins that are folders of data rather than code we load, a connector client that brings market data in as drafts, and a standing queue that tells you what needs attention across every project.

**7/**
The draft gate. Everything from outside — an assistant, a connector, a plugin, another tool — has to pass one visible gate. It becomes your project data when you accept it, and not a moment before.

**8/**
New in 1.0: restate a project in another currency. You enter the rate. Every amount moves in exact decimals. Percentages stay percentages — we never multiply a fee rate by an exchange rate.

**9/**
What is still true: installers are self-signed, so your OS will warn you. macOS auto-update is untested. The Linux snap can lose your plugin folder across an update. All documented, none hidden.

**10/**
It is AGPL and it is local-first, permanently: no cloud sync, no accounts, no telemetry, no payments, no autonomous browsing. Your files stay on your machine. That is the product, not a setting.

**11/**
1.0 is out now. Tell us where it breaks your workflow: github.com/getxeyronoxz/open-merchant/issues
