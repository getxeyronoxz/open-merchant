**1/**
We just shipped the first public alpha of Open Merchant — a local-first desktop workbench for one decision: is this product opportunity actually worth pursuing?

Demo in the README: github.com/getxeyronoxz/open-merchant

**2/**
The pitch: one project folder per decision. Objective, evidence, competitor listings, cost assumptions, and an evidence-linked report — instead of twelve tabs and a spreadsheet you'll never find again.

**3/**
The math is not AI. Unit economics run on arbitrary-precision decimals in a deterministic core pinned by golden fixtures. No floating point, no LLM anywhere near a calculation. Same inputs, same numbers, forever.

**4/**
Six AI assistants draft content — research plans, evidence entries, competitor rows, report sections, integrity checks. But every draft is marked, and nothing saves until you accept it. The machine proposes; you decide.

**5/**
Ground rules we refused to break: no cloud sync, no accounts, no telemetry, no payments, no autonomous browsing. Your assistants only see what you paste in. Your files stay on your machine.

**6/**
It also updates itself: passive delta updates from GitHub Releases, keyless local AI via Ollama or LM Studio if you want it, and side-by-side report diffs when you regenerate.

**7/**
What's next: signed installers on all platforms, then Phase 2 — market snapshots, margin monitoring, a decision journal.

Try the alpha and tell us where it breaks your workflow: github.com/getxeyronoxz/open-merchant/releases
